# Đêm Thạch Ma

Bản mẫu game phòng thủ quái vật trên điện thoại: camera làm nền, xoay máy làm ống ngắm, quái kéo đến trong cung 120° phía trước.

Chơi: mở trang GitHub Pages của repo này bằng Chrome trên Android, bấm Bắt đầu, cho phép camera.

## Tranh Sống (thư mục `sinh-vat/`)

Vẽ một sinh vật lên giấy, chụp lại, và xem nó sống dậy trong phòng qua camera. Chơi: mở `/sinh-vat/` trên trang GitHub Pages của repo này. Gắn Gemini (tùy chọn): xem `sinh-vat/HUONG-DAN-AI.md`.
